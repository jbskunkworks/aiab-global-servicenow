# Repository publication

Forgejo is the canonical code home. The GitHub repository is a publication mirror; its main branch is synchronized from the canonical repository and direct changes there may be overwritten. Resolve the canonical remote for your checkout before pushing changes or opening code reviews.

GitHub Issues is the issue inbox: https://github.com/jbskunkworks/aiab-global-servicenow/issues. Git mirrors do not copy issue discussions or pull requests. Existing release tags and ServiceNow instance branches are retained on both hosts.
